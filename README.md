# هايم (HAYM) — موقع تجاري عربي

موقع ثابت من ثلاث صفحات مترابطة بهوية علامة هايم للأزياء واللايف ستايل.

## البنية

```
index.html          الرئيسية
services.html       الخدمات الثلاث
contact.html        التواصل وواتساب والعنوان
style.css           التنسيق المشترك لكل الصفحات
assets/images/      الصور والرسوم التوضيحية
```

الصفحات تعمل مباشرة بفتح `index.html` في المتصفح، ولا تحتاج أي خادم أو أدوات تثبيت.

## تخصيص البيانات

- رقم واتساب المستخدم حاليًا تجريبي: `+966 50 000 0000`، ورابط المراسلة `https://wa.me/966500000000`. استبدل الرقم في جميع الصفحات الثلاث (في زر واتساب والتذييل) وفي `contact.html`.
- العنوان المستخدم `الرياض، المملكة العربية السعودية — حي العليا`. استبدله بعنوان النشاط الفعلي في `contact.html` وفي التذييل بالصفحات الثلاث.
- الألوان والخط في أعلى `style.css` داخل `:root` و`'Cairo'`.
- الصور جاهزة في `assets/images/` ويمكن استبدالها حسب التعليمات في `assets/images/README.md`.
