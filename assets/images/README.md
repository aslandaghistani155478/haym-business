# مجلد صور هايم

يحتوي هذا المجلد على رسوم توضيحية جاهزة (SVG) تعمل دون اتصال بالإنترنت ويمكن استبدالها بصور حقيقية بسهولة.

| الملف | مكان الاستخدام |
| --- | --- |
| `hero-fashion.svg` | صورة الصفحة الرئيسية في `index.html` |
| `service-apparel.svg` | الأزياء والهوديز في `services.html` ومعاينة الرئيسية |
| `service-custom.svg` | تيشيرتات ومنتجات مخصصة في `services.html` ومعاينة الرئيسية |
| `service-gifts.svg` | طلبات المجموعات والهدايا في `services.html` ومعاينة الرئيسية |
| `favicon.svg` | أيقونة التبويب في الصفحات الثلاث |

لاستبدال أي رسم بصورة فعلية:

1. ضع الصورة في هذا المجلد باسم إنجليزي صغير بلا مسافات، مثل `hero-fashion.jpg`.
2. عدّل قيمة `src` و`alt` في الملف الذي يستخدمها مع الحفاظ على المسار `assets/images/`.
3. إن احتفظت بالاسم نفسه مع تغيير الامتداد فقط، عدّل الامتداد في `src` فقط.

الصور الحالية قابلة للتغيير بالكامل دون تعديل أي تنسيق؛ الأبعاد مضبوطة عبر CSS باستخدام `object-fit: cover`.
